# Recipe Finder

A simple website that helps you discover recipes and find something delicious to cook!

🌐 **[Try Recipe Finder+](dodolino2024-wq.github.io/recipe-finder/)**

## ✨ Features

- 🔎 Search for recipes
- 🥕 Find meals by ingredients
- 🍽️ Explore different recipes
- 🎲 Discover random meals

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- TheMealDB API
- DummyJSON API
